RemoteMirror 지원

RemoteMirror는 iPhone/iPad에서 내 Mac의 화면을 보고 제어하는 앱입니다. 터치를 마우스처럼 쓸 수 있고, 실시간 한글 입력을 포함한 키보드 입력도 지원합니다. iPhone/iPad와 Mac 양쪽에 RemoteMirror 앱을 설치하세요. Mac 앱이 호스트 역할을 하며, App Store에서 같은 제품으로 제공됩니다.

요구 사항

  • iOS/iPadOS 26 이상, macOS 26 이상
  • 처음 페어링할 때는 두 기기가 같은 Wi‑Fi 네트워크에 있어야 합니다.

시작하기

  1. Mac에서 RemoteMirror를 열고, 요청이 나오면 '화면 기록'과 '손쉬운 사용' 권한을 허용합니다. 화면을 보여 주고 마우스·키보드 입력을 전달하는 데 필요합니다.
  2. Mac에서 '기기 추가'를 선택합니다.
  3. iPhone/iPad의 목록에서 내 Mac을 고르고 표시된 확인 코드가 서로 같은지 확인합니다(QR 코드 스캔도 가능). 그다음 Mac에서 승인합니다.
  4. iPhone/iPad에서 Mac을 눌러 연결합니다.

집 밖에서 접속하기 (선택)

  • Mac에서 '원격 접속 허용'을 켭니다.
  • 공유기가 NAT-PMP/PCP를 지원하면 포트가 자동으로 열립니다. 지원하지 않으면 공유기에서 직접 포트 포워딩을 설정해야 합니다.
  • 또는 선택 기능인 릴레이 방식(Tailcat)을 두 앱 모두에서 직접 선택해 사용할 수 있습니다.

구매 안내

앱은 무료로 내려받으며 3일 무료 체험이 제공됩니다. 이후 일회성 인앱 구매로 iPhone/iPad의 전체 기능이 열립니다. Mac 호스트 앱은 무료입니다. 앱에서 '구매 복원'을 눌러 이전 구매를 복원할 수 있습니다.

자주 묻는 질문

  • 목록에 Mac이 보이지 않아요. 같은 Wi‑Fi에 연결돼 있는지, Mac에서 RemoteMirror가 실행 중인지, iPhone/iPad에서 '로컬 네트워크' 권한이 허용돼 있는지 확인하세요.
  • 화면이 검게 나와요. Mac의 '화면 기록' 권한을 확인하세요.
  • 마우스/키보드가 동작하지 않아요. Mac의 '손쉬운 사용' 권한을 확인하세요.
  • 페어링이 실패해요. Mac에서 30초 안에 승인해야 합니다. 다시 시도해 주세요.

English

RemoteMirror lets you view and control your Mac's screen from iPhone/iPad, with touch as mouse and keyboard input including real-time Korean input. Install the app on both devices; the Mac app is the host.

  • Requires iOS/iPadOS 26+ and macOS 26+. Use the same Wi‑Fi for first pairing.
  • Setup: grant Screen Recording and Accessibility on the Mac, choose "Add device" on the Mac, pick the Mac on your iPhone/iPad, confirm the matching code (or scan the QR code), approve on the Mac within 30 seconds, then tap the Mac to connect.
  • Remote access is optional: enable "Allow remote access" on the Mac (automatic port mapping needs NAT-PMP/PCP, otherwise forward a port manually), or explicitly choose the optional relay mode (Tailcat) in both apps.
  • Free download with a 3-day trial, then a one-time in-app purchase unlocks full features on iPhone/iPad. The Mac host is free. Use Restore Purchases in the app.
  • Support: GitHub Issues. Privacy Policy
